# 🚀 NLP Smart Assistant

An advanced AI-powered **NLP Smart Assistant** built using **Python, FastAPI, NLP, and Machine Learning** to analyze incidents, process natural language queries, generate intelligent recommendations, and automate smart assistant workflows.

This project demonstrates the implementation of a modular AI assistant system with multiple processing engines including anomaly detection, reasoning, reporting, metrics analysis, remediation suggestions, and recommendation systems.

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Saee2803/NLP_Smart_Assistant.git
cd NLP_Smart_Assistant
```

---

## 2️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run Application

### Windows

```bash
start_server.bat
```

### Linux / Mac

```bash
bash start_server.sh
```

OR

```bash
python app.py
```
